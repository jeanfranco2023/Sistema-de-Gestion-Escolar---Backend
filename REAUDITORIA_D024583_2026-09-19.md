## Observaciones pendientes

### Alta — el commit publicado no compilaba desde limpio

Los 28 imports `java.util.Stream` demostraron que una compilación incremental puede ocultar errores presentes en Git. La corrección queda en el árbol local y debe consolidarse antes de considerar estable el commit.

### Media-alta — la puerta de calidad falla

Todas las pruebas pasan, pero `mvn verify` falla porque la cobertura de instrucciones es 59.7547% y el umbral es 60%. No debe reducirse el umbral para ocultarlo.

**Acción:** añadir pruebas útiles para ramas de autorización, errores transaccionales, rate limiting, webhooks y adapters hasta superar 60% con margen, idealmente 65%.

### Media — rate limiting no distribuido

El contador usa `ConcurrentHashMap`. Se reinicia al desplegar y cada réplica aplica un límite independiente. `application-prod.yml` fija `behind-trusted-proxy=true`; esto es correcto únicamente si el backend siempre está aislado detrás de un proxy que elimina la cabecera aportada por el cliente.

**Acción:** aplicar el límite en gateway/Cloudflare o Redis y documentar proxies confiables. Si existe acceso directo al backend, mantener la propiedad en `false`.

### Media — listados sin paginación

Persisten múltiples `findAll()` en módulos operativos. Esto puede degradar memoria y latencia cuando crezcan matrículas, pagos, incidencias, comunicaciones y datos biométricos.

**Acción:** añadir paginación o cursor en datos crecientes; conservar listas completas solo para catálogos pequeños.

### Media — vulnerabilidades de dependencias no certificadas localmente

CI ya hace obligatorio Dependency-Check, pero esta auditoría no obtuvo una base NVD actualizada. Se mantiene el riesgo hasta observar una ejecución exitosa del job con datos recientes.

**Acción:** configurar `NVD_API_KEY`, cachear la base por fecha y conservar `failBuildOnCVSS=8`.

### Baja — consulta de usuario en cada solicitud autenticada

La sincronización de roles vivos mejora la seguridad, pero añade una consulta a PostgreSQL por petición. Con alta carga puede convertirse en presión adicional sobre Supabase/Hikari.

**Acción:** medir latencia y considerar caché corta con invalidación por usuario o una `securityVersion` incluida en JWT.

### Baja — código residual

`JwtAuthenticationFilter` todavía lee `roles` desde el token en una variable que no usa. Debe eliminarse para evitar confusión. También puede retirarse la configuración explícita de `PostgreSQLDialect`, ya que Hibernate la detecta automáticamente.
